# AI Science Discoverer 🧪
نظام تطوري ذكي لاكتشاف ومحاكاة القوانين الفيزيائية والمعادلات الرياضية غير المسبوقة باستخدام التوليد الرمزي والبرمجة الجينية.

## الميزات الرئيسية:
- **توليد معادلات فريدة (Novel Equation Generation):** لا يعتمد على قوانين جاهزة بل ينشئ صيغاً تفاضلية جديدة تماماً.
- **البرمجة الجينية (Genetic Programming):** استخدام عمليات الطفرات والجينات لتطوير الصيغ الأكثر استقراراً وفائدة.
- **محاكاة فضاء الطور (Phase Space Simulation):** رسم حركة الموضع والسرعة ومخطط الطور لكل نظرية تم اكتشافها.
- **تصدير البيانات:** حفظ الكتالوج بملفات JSON و CSV.
